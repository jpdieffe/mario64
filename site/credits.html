Built on great work.

Original Super Mario 64 game, characters, music and assets © Nintendo. This is an unofficial fan project, with no Nintendo affiliation.

The native multiplayer game is SM64CoopDX by the Coop Deluxe Team, building on djoslin0’s sm64ex-coop and the SM64 decompilation community. The browser engine and touch controls come from zalo’s Emscripten web port. PeerJS provides WebRTC signaling and data connections.

The animated Yoshi model is credited to the Coop Team in ULTRA BROS TEAM?s bundled Extra Characters Plus pack. This game adds an original tongue mesh and tongue/fireball gameplay.

This project adds the three-player room flow, mobile interface, separate health display, and synchronized team-death rules. Player collision and head bouncing use the co-op engine’s native physics.
